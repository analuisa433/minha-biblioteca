# Minha Biblioteca

Aplicação web desenvolvida em React para pesquisar livros e organizar uma biblioteca pessoal. O sistema utiliza a API Open Library para consultar informações sobre livros.

## Funcionalidades

- Pesquisar livros pelo título.
- Visualizar capa, autor e ano de publicação.
- Adicionar livros à biblioteca pessoal.
- Alterar o status de leitura:
  - Quero ler
  - Lendo
  - Concluído
- Avaliar livros de 0 a 5 estrelas.
- Remover livros da biblioteca.
- Consultar o histórico de leitura, separado por status.

## Tecnologias utilizadas

- React
- JavaScript
- HTML
- CSS
- Vite
- API Open Library

## Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/analuisa433/minha-biblioteca.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd minha-biblioteca
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Acesse no navegador o endereço indicado pelo terminal.

## API utilizada

O projeto utiliza a [Open Library API](https://openlibrary.org/developers/api), que permite pesquisar livros e obter informações como título, autor, ano de publicação e capa.
